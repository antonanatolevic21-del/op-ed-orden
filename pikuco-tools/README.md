# Пикуко — инструменты

Расширение для Chrome и браузеров на Chromium, которые поддерживают Manifest V3. Версия **0.5.13**.

[Скачать ZIP](https://raw.githubusercontent.com/antonanatolevic21-del/op-ed-orden/pikuco-tools/pikuco-tools/pikuco-tools.zip) · [Посмотреть исходники](./src/)

## Что умеет расширение

- Сохраняет переносы строк и пустые строки при вставке текста в редактор Пикуко.
- Применяет выбранные пресеты при создании теста. Поддерживаются турниры, викторины, идентификация и диаграммы, челленджи и тирлисты.
- По выбору пропускает декоративную заставку и снимает клиентский атрибут `maxlength` у текстовых полей. Ограничения при сохранении по-прежнему определяет сайт.
- Добавляет кнопку «Посмотреть карточку» в окно возобновления незавершённого теста. Просмотр карточки сохраняет текущий прогресс.
- Добавляет вкладку «Подписки» в каталог тестов. Сначала загружает тесты приоритетных авторов, затем остальных по рейтингу. В личном кабинете можно отметить звёздочкой до десяти авторов. Лента сортирует карточки от новых к старым и показывает метку прохождения, когда этот статус доступен в разметке сайта.
- Выводит обложку блога широким баннером в шапке его карточки.

В ленте подписок могут быть доступны только последние тесты автора. Подгрузка более старых публикаций зависит от того, какие страницы и кнопки продолжения удаётся распознать в списке автора.

## Установка

1. Скачай [готовый ZIP расширения](https://github.com/antonanatolevic21-del/op-ed-orden/raw/refs/heads/pikuco-tools/pikuco-tools/pikuco-tools.zip) и распакуй его в отдельную папку.
2. Открой `chrome://extensions` и включи «Режим разработчика».
3. Нажми «Загрузить распакованное расширение» и выбери папку, в которой находится `manifest.json`.
4. Открой или обнови вкладку Пикуко. Настройки доступны по кнопке расширения.

Переключатели в меню применяются на открытых вкладках Пикуко. Новые отметки пресетов действуют и в открытом редакторе нового теста. Снятие отметки пресета прекращает его автоматическое применение.

Для обновления замени файлы в уже подключённой папке, нажми «Обновить» на странице расширений и перезагрузи вкладку Пикуко. Исходники готовы к запуску, отдельная сборка не требуется.


## Совместимость с браузерами

Расширение использует Manifest V3. Ниже указано, где браузер позволяет загрузить распакованное расширение. Работа всех функций в каждом из этих браузеров отдельно не проверялась.

| Браузер | Как загрузить |
| --- | --- |
| **Chrome и Chromium на компьютере** | Открой `chrome://extensions`, включи режим разработчика и выбери папку с `manifest.json`. [Инструкция Chrome](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world#load-unpacked) |
| **Microsoft Edge на компьютере** | Те же шаги на `edge://extensions`. [Инструкция Microsoft](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading) |
| **Brave на компьютере** | Те же шаги на `brave://extensions`. [Инструкция Brave](https://community.brave.app/t/debugging-custom-extension-add-ons/169217) |
| **Opera на компьютере** | Те же шаги на `opera:extensions`. В Opera GX можно попробовать тот же способ. [Инструкция Opera](https://help.opera.com/en/extensions/testing/) |
| **Vivaldi на компьютере** | Те же шаги на `vivaldi://extensions`. [Инструкция Vivaldi](https://help.vivaldi.com/desktop/appearance-customization/extensions/) |
| **Яндекс Браузер на Android** | Открой `browser://extensions`, включи режим разработчика и выбери файл `manifest.json` в распакованной папке. [Инструкция Яндекса](https://yandex.ru/support/browser-mobile-android-phone/ru/personal-settings/extensions) |
| **Vivaldi на Android** | Включи «Версия для ПК», открой меню расширений → «Управление расширениями» и выбери папку в режиме разработчика. [Инструкция Vivaldi](https://help.vivaldi.com/android/android-tools/extensions-on-android/) |

### Где этот ZIP не подходит для обычной установки

| Браузер | Что доступно |
| --- | --- |
| **Chrome на Android и iPhone** | Мобильный Chrome предлагает добавить расширение в Chrome на компьютере. Локальной установки из ZIP для мобильного Chrome нет. [Справка Google](https://support.google.com/chrome/answer/2664769) |
| **Яндекс Браузер на компьютере** | Для локального тестирования Яндекс описывает установку пакета `crx3`. Здесь опубликована ZIP-сборка. [Справка Яндекса](https://yandex.com/support/browser/ru/personalization/extension) |
| **Firefox на компьютере** | Можно попробовать временную загрузку через `about:debugging` до перезапуска браузера. Совместимость не проверена. [Инструкция Mozilla](https://extensionworkshop.com/documentation/develop/temporary-installation-in-firefox/) |
| **Firefox на Android** | Обычная установка идёт через каталог дополнений. Эта сборка для него не выпускалась. [Справка Mozilla](https://support.mozilla.org/en-US/kb/find-and-install-add-ons-firefox-android) |
| **Safari на Mac и iPhone** | Для обычной установки нужна отдельно упакованная версия Safari. Совместимость этой сборки не проверена. [Документация Apple](https://developer.apple.com/safari/extensions/) |

## Файлы расширения

| Файл | Назначение |
| --- | --- |
| [`manifest.json`](./src/manifest.json) | Описывает расширение, разрешение `storage`, окно настроек и порядок подключения скриптов и стилей на Пикуко. |
| [`popup.html`](./src/popup.html) | Разметка и стили окна настроек. |
| [`popup.js`](./src/popup.js) | Загружает и сохраняет основные переключатели в `chrome.storage.local`. |
| [`popup-test-presets.js`](./src/popup-test-presets.js) | Формирует список пресетов по форматам и сохраняет выбранные пункты. |
| [`test-presets.js`](./src/test-presets.js) | Хранит список форматов, параметры пресетов и ключи настроек. |
| [`apply-test-presets.js`](./src/apply-test-presets.js) | Определяет формат нового теста и применяет выбранные пресеты через элементы редактора. |
| [`paste-with-paragraphs.js`](./src/paste-with-paragraphs.js) | Обрабатывает вставку текста с переносами в редакторе. |
| [`page-options.js`](./src/page-options.js) | Реализует пропуск заставки и снятие клиентских ограничений длины полей. |
| [`skip-intro.css`](./src/skip-intro.css) | Скрывает отмеченные расширением элементы заставки и задаёт непрозрачный фон штатной проверке сайта. |
| [`resume-card.js`](./src/resume-card.js) | Добавляет просмотр карточки из окна возобновления теста и управляет возвратом к этому окну. |
| [`resume-card.css`](./src/resume-card.css) | Оформляет кнопки просмотра и возврата, скрывает помеченные скриптом слои окна. |
| [`following-feed.js`](./src/following-feed.js) | Читает список подписок, управляет приоритетами, очередью загрузки и выводом карточек. |
| [`following-author-feed.js`](./src/following-author-feed.js) | Читает страницы тестов авторов, извлекает данные карточек и обложек, обрабатывает пагинацию и сортирует публикации. |
| [`following-feed.css`](./src/following-feed.css) | Оформляет вкладку «Подписки», индикатор загрузки, звёздочки и запасной вид карточек. |
| [`blog-cover.css`](./src/blog-cover.css) | Выводит существующую обложку блога широким баннером над названием. |

Настройки и звёздочки хранятся в текущем профиле браузера.
